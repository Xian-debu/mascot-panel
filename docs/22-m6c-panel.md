# M6c 面板视觉（品牌位 + 空态）

日期：2026-10-22 夜。M6b 之后用户仍可感知的差距主要在面板：旧版有星座风 SVG 时钟头像、
青→紫渐变标题、空态插画；本版只有一行标题和纯文字提示。

## 1. 标题栏品牌位

- **头像**：`js/clock.js` 把旧版 `static/pet-clock.js` 的设计移植成 SVG：12 个刻度点，
  时针/分针最近的两个刻度会按正弦呼吸发光（相位相反），中心宝石；点一下 = 收进小球。
  颜色全部由 CSS 变量给（JS 只改半径/class），遵守“颜色单源”契约。
- **标题**：青→紫渐变文字（`background-clip:text`），紫色新增 `--violet #a78bfa`。
  它只用于品牌位，不参与状态语义（状态仍只用青/琥珀/红）。
- **状态灯**保留在标题右侧（M5 已实现四态动画），和 chip 一起读。

## 2. 空态

消息为空时显示四角星（青紫渐变 + 呼吸）+ “在的，说点什么吧” + 键盘提示。

**坑**：`renderMessages` 用 signature 去重，初值是空串 `''`；空列表的 signature 也是 `''`，
于是**首帧空态永远不会渲染**（窗口一片黑）。改成 `null` 初值后正常。
这类“空集合与初值撞车”的去重 bug 只有真机截图能看出来，单测不会报。

## 3. 动效

- 面板出现：160ms 上浮 + 淡入（`prefers-reduced-motion` 下关闭）。
- 状态灯：idle 呼吸 / working 脉冲 / awaiting 慢闪 / error 常亮（M5 已有）。
- 头像刻度：1s 更新一次指针位置，白色分针、青色时针。

## 4. 验证

- Linux：ruff 0 / pyright 0 / pytest 全绿；契约测试新增 `M.mountClock`、`.empty-star` 标记。
- Windows 真机：`--provider null` 截图 `evidence/m6c-panel.png`（头像 + 渐变标题 + 状态灯 + 消息）；
  `--provider wsl --provider-url http://127.0.0.1:9` 截图 `evidence/m6c-empty.png`（降级横幅 + 空态星）。

## 5. 遗留

- 头像时钟在 26px 下指针较细，高 DPI 下仍清楚；若做 125% 以下缩放需再看。
- 面板仍然“硬切”出现/消失，没有和球之间的过渡动画。
