## 2. 草稿为什么从 localStorage 改成落盘

- WebView 加载的是**字符串 HTML**，源是 `about:blank`（不透明源），`localStorage` 写入可能不报错但**进程重启就没了**。
- 早期实现还把它包在 try/catch 里 → 失败静默，表现就是"说过要存但重启没恢复"。
- 现在 `runtime.py` 提供 `draft()` / `save_draft(text)` 桥，写 `draft.txt`（tmp + replace 原子写，空内容直接删文件，上限 4000 字）；前端 input 事件 400ms 防抖，发送时立刻写空。
